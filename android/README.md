# 이미지 폴더 알림 — Galaxy S23 Ultra

## 설치와 사용
1. ImageFolderAlarm-1.4.apk를 휴대폰에 복사해 설치합니다. 직접 설치하는 APK이므로 휴대폰에서 해당 설치 경로의 앱 설치 허용이 필요할 수 있습니다.
2. 앱을 열고 책 이름(예: 어린 왕자)을 입력합니다.
3. 폴더 선택에서 캡처 전용 폴더를 선택하고 접근을 허용합니다.
4. 감시 시작을 누릅니다. 알림 권한을 허용한 경우 시작 버튼을 다시 누릅니다.
5. 새 이미지가 추가되면 수 증가 알림을 보내고, 저장이 안정된 뒤 어린 왕자_001.png, 어린 왕자_002.png 순서로 이름을 변경합니다.
6. 감시 중지 버튼 또는 감시 알림의 중지 버튼으로 감시와 자동 이름 변경을 멈춥니다.
7. 마지막 번호 이미지 한 장 삭제를 누르면 현재 책 이름의 가장 큰 번호 파일명을 보여줍니다. 한 장 삭제를 확인하면 영구 삭제합니다. 반복하면 번호 역순으로 한 장씩 지울 수 있습니다.

## 번호와 삭제 규칙
기존 파일명은 자동 변경하지 않습니다. 번호는 해당 책 파일 중 가장 큰 번호의 다음 번호를 사용하며, 파일이 없으면 001부터 시작합니다. 999 다음은 1000입니다. 원래 확장자는 유지합니다. 마지막 번호 파일을 지우면 다음 캡처는 남은 가장 큰 번호의 다음 번호를 사용합니다. 다른 책이나 다른 이름의 파일은 삭제 대상으로 삼지 않습니다. 삭제 확인 중 마지막 파일이 달라지면 삭제하지 않고 다시 확인하도록 안내합니다. 파일 변경과 삭제는 앱 안에서 서로 겹치지 않게 처리합니다.

## 감시와 알림
선택 폴더 바로 아래의 모든 새 이미지가 대상입니다. 실제 스크린샷인지 구분하지 않으므로 캡처 전용 폴더를 선택하세요. 하위 폴더는 제외합니다. 1초마다 수를 확인하며, 파일 크기가 두 검사에서 같고 0보다 클 때 이름 변경을 시도합니다. 같은 검사 사이에 삭제와 추가가 생겨 전체 수가 늘지 않아도 새 파일은 이름 변경 대상이 됩니다. 이미지 수 증가와 이름 변경 완료는 각각 알림으로 표시될 수 있습니다.

삼성 설정에서 앱 알림의 새 이미지 알림을 소리 및 팝업으로 허용하세요. 앱 정보 → 배터리 → 제한 없음 설정이 백그라운드 감시에 도움이 됩니다. 화면 꺼짐, 절전, 방해 금지 상태에 따라 확인이나 알림이 지연될 수 있습니다. 재부팅/강제 종료 후에는 앱에서 직접 다시 시작해야 합니다. 감시 중지는 이미 시작된 이름 변경 한 건을 마칠 수 있습니다. 접근 권한이 없어지면 다시 폴더를 선택하세요. 인터넷 권한은 없습니다.

## 검증 범위
Java 컴파일, DEX 생성, APK 패키징, v2/v3 서명 검증, 번호 처리 테스트 14개 통과. 실제 Galaxy S23 Ultra 설치 및 실행 검증은 미실시입니다. 먼저 테스트용 폴더에서 시작/중지, 연속 캡처, 번호, 영구 삭제를 확인하세요.

## 개발
소스는 image-folder-alarm 폴더에 있습니다. scripts/build_folder_alarm.py가 tmp/image-folder-alarm에 준비된 도구로 빌드하며 결과와 검증 보고서는 output/image-folder-alarm에 저장합니다. 시스템 Java/Android 설정을 변경하지 않습니다. 개발용 서명을 사용했습니다. 키와 빌드 캐시는 배포 소스 ZIP에 포함하지 않습니다.


## v1.1 알림 점검
알림 테스트와 팝업 알림 설정 버튼, 최근 감지 기록을 추가했습니다. 캡처 알림과 이름 변경 결과 알림을 분리했습니다. 기존 앱을 삭제하지 말고 업데이트 설치하세요. 시스템의 조용한 알림·팝업 차단·방해 금지는 앱이 강제로 해제하지 않습니다.


## v1.2 작은 번호창
기존 앱을 삭제하지 않고 업데이트 설치하세요. 작은 번호창 표시를 켜고 다른 앱 위에 표시 권한을 허용한 뒤 앱으로 돌아와 감시 시작을 누르세요. 창에는 책 이름과 마지막으로 정리된 번호가 표시됩니다. 이미지가 저장되고 이름 변경이 끝나면 번호가 바뀝니다. 드래그로 이동하고 ×로 닫습니다. 창을 닫아도 감시는 계속되며 앱에서 다시 표시할 수 있습니다. 감시 중지 시 창도 사라집니다. 창이 보이는 동안에는 반복 캡처 알림을 보내지 않습니다. 검사 주기는 1초이며 저장/절전 상태에 따라 늦어질 수 있습니다. 창이 스크린샷에 포함되지 않는다고 보장하지 않으므로 테스트용 캡처에서 확인하세요.


## v1.3 빠른 번호 표시
새 파일이 감지되면 번호를 먼저 배정해 상주창에 표시합니다. ‘정리 중’은 아직 이름 변경 대기 중이라는 뜻입니다. 변경 이벤트와 0.2초 간격 확인을 함께 사용합니다. 캡처 버튼 자체는 감지하지 않으므로 누르는 순간과 완전히 동시 표시를 보장하지 않습니다. 실제 속도는 휴대폰의 파일 생성·폴더 조회 속도와 절전 상태에 따라 다르며 실기기 속도 검증은 아직입니다. 기존보다 배터리 사용이 늘어날 수 있습니다. 기존 앱 위에 업데이트 설치하세요.
