# 이미지 폴더 알림

Galaxy S23 Ultra를 위해 만든 안드로이드 캡처 정리 앱과 다운로드 안내 사이트입니다.

- 폴더 직접 선택, 감시 시작·중지, 이미지 추가 알림
- 책 이름 + 001부터 자동 파일명 변경
- 가장 큰 번호부터 확인 후 한 장씩 영구 삭제

웹사이트는 `docs/`에 있고 APK는 `docs/downloads/ImageFolderAlarm-1.6.apk`에 있습니다. Android 소스는 `android/`, 설치 안내는 `사용방법.md`, 빌드 검증 결과는 `validation.json`에 있습니다.

빌드·번호 처리 14개 테스트·서명 검증 통과. Galaxy S23 Ultra 실기기 검증은 미실시입니다.

사이트: https://kingspledu.github.io/image-folder-alarm/

GitHub Pages 배포 소스: main 브랜치의 /docs. 저장소와 다운로드 사이트는 공개되어 있습니다.



## v1.1 알림 점검
알림 테스트와 팝업 알림 설정 버튼, 최근 감지 기록을 추가했습니다. 캡처 알림과 이름 변경 결과 알림을 분리했습니다. 기존 앱을 삭제하지 말고 업데이트 설치하세요. 시스템의 조용한 알림·팝업 차단·방해 금지는 앱이 강제로 해제하지 않습니다.


## v1.2 작은 번호창
기존 앱을 삭제하지 않고 업데이트 설치하세요. 작은 번호창 표시를 켜고 다른 앱 위에 표시 권한을 허용한 뒤 앱으로 돌아와 감시 시작을 누르세요. 창에는 책 이름과 마지막으로 정리된 번호가 표시됩니다. 이미지가 저장되고 이름 변경이 끝나면 번호가 바뀝니다. 드래그로 이동하고 ×로 닫습니다. 창을 닫아도 감시는 계속되며 앱에서 다시 표시할 수 있습니다. 감시 중지 시 창도 사라집니다. 창이 보이는 동안에는 반복 캡처 알림을 보내지 않습니다. 검사 주기는 1초이며 저장/절전 상태에 따라 늦어질 수 있습니다. 창이 스크린샷에 포함되지 않는다고 보장하지 않으므로 테스트용 캡처에서 확인하세요.


## v1.3 빠른 번호 표시
새 파일이 감지되면 번호를 먼저 배정해 상주창에 표시합니다. ‘정리 중’은 아직 이름 변경 대기 중이라는 뜻입니다. 변경 이벤트와 0.2초 간격 확인을 함께 사용합니다. 캡처 버튼 자체는 감지하지 않으므로 누르는 순간과 완전히 동시 표시를 보장하지 않습니다. 실제 속도는 휴대폰의 파일 생성·폴더 조회 속도와 절전 상태에 따라 다르며 실기기 속도 검증은 아직입니다. 기존보다 배터리 사용이 늘어날 수 있습니다. 기존 앱 위에 업데이트 설치하세요.

## v1.4 알림 터치
알림 본문을 눌러도 앱을 열지 않습니다. 알림의 감시 중지 버튼은 유지했습니다. 번호창을 눌러도 앱으로 이동하지 않습니다. 기존 앱을 지우지 않고 업데이트 설치하세요.


## v1.5 밀리 캡처 버튼 터치 (S23 Ultra)
1. 기존 앱 위에 v1.5를 업데이트 설치합니다.
2. 앱에서 ‘밀리 캡처 접근성 켜기’를 누르고, 접근성 설정에서 ‘이미지 폴더 알림 · 밀리 버튼 터치’를 직접 켭니다.
3. 책 이름·저장 폴더를 정하고 작은 번호창 표시 권한을 허용한 뒤 감시를 시작합니다.
4. 밀리의 서재에서 카메라 버튼이 보이는 읽기 화면을 엽니다.
5. 작은 창의 ‘위치’를 누르고 노란 조준점 중심을 밀리의 카메라 버튼 위에 드래그한 뒤 ‘저장’을 누릅니다.
6. 작은 창의 ‘캡처’를 누르면 밀리 화면인지 확인하고 등록된 위치를 한 번 터치합니다. 밀리에 저장 확인 단계가 뜨면 직접 처리합니다. 파일 생성이 감지되면 번호가 올라갑니다.
7. 좌표를 숫자로 바꾸려면 앱의 ‘캡처 X·Y 좌표 직접 수정’을 사용합니다. 단위는 픽셀이고 왼쪽 위가 0,0입니다. 현재 화면 해상도를 함께 표시합니다. 화면 방향이나 해상도를 바꾸면 다시 등록합니다.

사진을 바탕으로 임의 좌표를 고정하지 않았습니다. 실제 버튼 위치를 등록해야 합니다. 앱은 화면을 촬영하지 않고 사용자가 누를 때만 등록한 위치를 한 번 터치합니다. 밀리 이외의 화면에서는 터치하지 않습니다. 접근성으로 현재 화면의 앱 식별자만 확인하며 책 본문을 수집하거나 전송하지 않습니다. 번호는 실제 생성 파일 감지 후 갱신되며 버튼 누름만으로 성공한 것으로 세지 않습니다. 빌드·서명 및 설정 검증 완료, 실기기 밀리 버튼 동작은 미검증입니다.


## v1.6 마지막 이미지 미리보기와 삭제
상주창의 ‘마지막 이미지 / 삭제’를 누르면 앱을 열지 않고 선택 폴더에서 현재 책 이름의 가장 큰 번호 이미지를 보여줍니다. 정리가 끝난 파일 기준입니다. 저장·이름 변경 중이면 완료 후 확인하거나 새로고침을 누르세요. 미리보기를 열어둔 동안 다음 번호 파일의 정리가 끝나면 표시를 갱신합니다.

‘한 장 삭제’를 누르고 파일명을 확인한 뒤 ‘영구 삭제’를 누르면 미리본 마지막 파일 한 장만 지워지고 이전 이미지를 보여줍니다. 확인 중 새 마지막 파일이 생기거나 파일이 없어지면 삭제하지 않고 다시 보여줍니다. 삭제는 휴지통 이동 없이 영구 적용됩니다. 다른 책 이름이나 번호 없는 이미지는 대상이 아닙니다. 밀리 앱 버튼 자동 터치와 독립된 기능이며 접근성 권한 없이도 사용할 수 있습니다.

미리보기는 휴대폰에서 파일을 읽어 작게 표시하며 업로드하지 않습니다. 빌드·번호 테스트·서명 검증 완료, 실기기 미리보기·삭제 동작은 아직 미검증입니다.
