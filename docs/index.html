  3. 3

    알림을 허용하고 감시 시작

    알림 권한을 허용한 뒤 시작 버튼을 다시 누릅니다. 팝업은 삼성 알림 설정에서, 백그라운드 감시는 배터리 ‘제한 없음’에서 설정하세요.

v1.6 · 마지막 이미지 확인하고 한 장 삭제

상주창의 ‘마지막 이미지 / 삭제’를 누르면 현재 책의 가장 큰 번호 이미지를 앱 전환 없이 미리봅니다. ‘한 장 삭제’에서 파일명을 확인하고 ‘영구 삭제’를 누르면 한 장만 지워지고 이전 이미지가 표시됩니다. 확인 중 마지막 파일이 바뀌면 삭제하지 않습니다. 저장·이름 변경 대기 중인 파일은 아직 미리보기에 나오지 않을 수 있습니다. 이 기능은 밀리 접근성을 켜지 않아도 사용할 수 있습니다.

v1.5 · 밀리 버튼 터치 + 좌표 수정

앱에서 ‘밀리 캡처 접근성 켜기’를 선택하고 해당 서비스를 직접 켜세요. 밀리 화면의 상주창에서 ‘위치’를 눌러 조준점 중심을 카메라 버튼에 맞추고 저장합니다. 이후 상주창의 ‘캡처’가 등록한 위치를 한 번 누릅니다. X·Y 픽셀 좌표는 앱에서도 직접 수정할 수 있습니다. 화면 방향·해상도가 바뀌면 다시 등록하세요. 화면 캡처 방식은 사용하지 않으며 밀리의 저장 확인창 등이 나오면 해당 단계는 직접 진행해야 합니다. S23 Ultra 실기기 검증은 아직입니다.

v1.4 · 알림을 눌러도 화면 유지

감시 알림, 캡처 알림, 이름 변경 결과, 테스트 알림을 눌러도 앱으로 이동하지 않습니다. 알림의 중지 버튼은 계속 동작합니다. 작은 번호창도 눌러서 앱이 열리지 않습니다.

v1.4 · 번호부터 빠르게

새 파일이 보이는 즉시 번호를 먼저 배정하고, 저장과 이름 변경은 뒤에서 처리합니다. 캡처 버튼 자체를 감지하는 기능은 아니므로 버튼과 완전히 동시에 바뀌는 것을 보장하지 않습니다. 실제 지연은 휴대폰의 파일 생성·폴더 제공 속도에 따라 다릅니다. 빠른 확인은 기존보다 배터리를 더 사용할 수 있습니다.

v1.4 · 번호부터 빠르게

새 파일이 보이는 즉시 번호를 먼저 배정하고, 저장과 이름 변경은 뒤에서 처리합니다. 캡처 버튼 자체를 감지하는 기능은 아니므로 버튼과 완전히 동시에 바뀌는 것을 보장하지 않습니다. 실제 지연은 휴대폰의 파일 생성·폴더 제공 속도에 따라 다릅니다. 빠른 확인은 기존보다 배터리를 더 사용할 수 있습니다.

v1.4 · 화면 위에 머무는 작은 번호창

‘작은 번호창 표시’를 켜고 ‘다른 앱 위에 표시’를 허용한 뒤 감시를 시작하세요. 책 이름과 새 이미지에 배정한 번호가 화면 위에 표시됩니다. 드래그로 옮기고 ×로 닫을 수 있습니다. 닫아도 감시는 계속됩니다. 표시 중에는 캡처마다 팝업을 반복하지 않습니다. 변경 이벤트와 0.2초 간격으로 확인해 새 파일이 보이면 번호부터 올립니다. 이름 변경은 저장이 안정된 뒤 처리합니다. 상주창이 스크린샷에 포함되는지는 기기에서 확인하세요.

캡처 중 팝업 알림이 안 보이나요?

v1.1에는 ‘알림 테스트’, ‘팝업 알림 설정’, 최근 감지 기록이 추가되었습니다. 기존 앱을 지우지 않고 업데이트 설치하세요. 테스트 알림이 알림창에만 보인다면 앱의 ‘팝업 알림 설정’에서 소리 및 팝업을 허용하세요. 방해 금지나 휴대폰의 알림 제한에 따라 팝업은 표시되지 않을 수 있습니다. 테스트는 되는데 캡처를 감지하지 못한다면 선택한 폴더와 실제 캡처 저장 위치가 같은지 확인하세요.

변경 이벤트와 0.2초 간격으로 확인하며 절전 중에는 지연될 수 있습니다. 재부팅·강제 종료 후에는 감시를 다시 시작하세요. 인터넷 권한은 사용하지 않습니다.
