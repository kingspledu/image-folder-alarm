01 / 감지

새 캡처를 놓치지 않게

선택한 폴더의 이미지 수가 늘면 알림을 보냅니다. 감시는 원할 때 켜고 끌 수 있어요.

02 / 정리

책 이름 + 001부터

새 이미지만 자동으로 이름을 바꿉니다. 기존 파일과 확장자를 유지하고, 사용 중인 번호 뒤로 이어갑니다.

03 / 되돌리기

현재 책의 가장 큰 번호부터 한 장씩. 파일명을 보고 확인한 다음 영구 삭제합니다.

바로 APK를 받을 수 있습니다.

  1. 1

    APK를 내려받아 설치하세요

    다운로드한 파일을 엽니다. 휴대폰이 요청하면 해당 설치 경로의 앱 설치를 허용하세요.

  2. 2

    책 이름과 캡처 폴더를 정하세요

    앱에 책 이름을 입력하고 폴더 접근을 허용합니다. 다른 이미지가 섞이지 않도록 캡처 전용 폴더를 권장합니다.

  3. 3

    알림을 허용하고 감시 시작

    알림 권한을 허용한 뒤 시작 버튼을 다시 누릅니다. 팝업은 삼성 알림 설정에서, 백그라운드 감시는 배터리 ‘제한 없음’에서 설정하세요.

설치 전에 알아두세요

폴더 바로 아래의 새 이미지가 대상입니다. 기존 이미지와 하위 폴더는 변경하지 않습니다. 삭제는 휴지통 이동 없이 영구 적용됩니다.

약 3초마다 확인하며 절전 중에는 지연될 수 있습니다. 재부팅·강제 종료 후에는 감시를 다시 시작하세요. 인터넷 권한은 사용하지 않습니다.

개발용 서명 APK입니다. 빌드·번호 처리 테스트 14개·서명 검증을 통과했으며, S23 Ultra 실기기 검증은 아직입니다. 테스트용 폴더에서 먼저 확인하세요.
