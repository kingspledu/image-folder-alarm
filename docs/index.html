v1.11 · 접근성 기능 제거, 수동 캡처용

자동 터치용 접근성 서비스와 관련 코드·설정을 설치 APK에서 제거했습니다. 밀리의 캡처 버튼은 직접 누릅니다. 상주 번호창·미리보기·한 장 삭제·중복 및 페이지 보정·ZIP·Google Drive 공유는 유지했습니다. 상주창에 필요한 다른 앱 위에 표시 권한은 남아 있습니다. 앱 식별자와 업데이트 서명은 동일합니다. Google Play 프로텍트의 설치 허용을 보장하지 않으며 실제 기기에서 다시 확인해야 합니다.

v1.10 · 책 캡처를 ZIP으로 Google Drive에

앱의 ‘책 캡처 ZIP / Google Drive’ → ‘ZIP 만들기’를 누르세요. 현재 책의 최종 번호 이미지만 묶고 백업·보정 대기 파일은 제외합니다. 검증 완료 후 ‘Google Drive에 저장’에서 계정·폴더를 골라 저장합니다. 앱에서 구글 계정 비밀번호를 받지 않습니다. 실제 업로드 상태는 Drive에서 확인하세요. 다른 앱으로 공유하거나 파일 저장 위치를 선택할 수도 있습니다. 원본과 이전 ZIP은 자동 삭제하지 않습니다.

v1.9 · 상주창 숫자가 시작 페이지

‘시작 페이지’에 016을 지정하면 다음 첫 캡처의 실제 페이지 기준을 16으로 잡습니다. 새 묶음은 별도 보관하고 ‘중복 / 구간 보정 → 종료·분석’에서 중복과 기존 일치 이미지를 함께 비교해 번호를 제안합니다. 확인 후 적용하면 교체 원본은 백업합니다. 중간 보정은 첫 장과 마지막 장이 기존 페이지와 같도록 앞뒤를 겹쳐 찍어야 합니다. 예전에 지정한 페이지와 충돌하면 적용하지 않습니다. 캡처 중 표시는 임시이며 중복을 뺀 번호는 분석 결과에서 확인하세요. ‘끝에 이어찍기’로 일반 저장으로 돌아갑니다. 미확인 구간이나 밀리 페이지 숫자를 이미지 없이 알아내는 기능은 아닙니다.

v1.9 · 겹쳐 다시 캡처하고 빠진 구간 보정

상주창에서 ‘중복 / 구간 보정’ → ‘재캡처 시작/추가’를 누릅니다. 밀리에서 빠진 구간 앞뒤의 이미 있던 페이지까지 순서대로 겹쳐 캡처한 뒤 ‘종료·분석’을 누르세요. 앞뒤의 정확히 같은 이미지로 연결 위치를 찾아 삽입·교체 순서를 제안합니다. 이미지를 넘겨 확인하고 적용하면 중복·교체 원본은 __backup_ 파일로 보관하고 번호는 001부터 다시 맞춥니다. 밀리 페이지 번호를 읽는 기능은 아니며 같은 페이지라도 화면 크기·배치가 달라 일치하지 않으면 자동 연결하지 않습니다. 기존 중복도 별도로 검사하고 보관 처리할 수 있습니다.

v1.7 · 표시 숫자를 자유롭게 보정

상주창에서 −1 / +1로 표시 번호를 바꾸거나 ‘표시 보정’에 원하는 차이를 직접 입력하세요. 실제 번호 50에 −7을 입력하면 43, +5를 입력하면 55입니다. 다음 캡처에도 차이를 유지합니다. 보정은 책별로 저장되며 초기화하면 원래 번호로 돌아갑니다. 표시는 0보다 작아지지 않습니다. 파일명, 실제 이미지, 미리보기와 삭제 순서는 바뀌지 않습니다.

v1.7 · 마지막 이미지 확인하고 한 장 삭제

상주창의 ‘마지막 이미지 / 삭제’를 누르면 현재 책의 가장 큰 번호 이미지를 앱 전환 없이 미리봅니다. ‘한 장 삭제’에서 파일명을 확인하고 ‘영구 삭제’를 누르면 한 장만 지워지고 이전 이미지가 표시됩니다. 확인 중 마지막 파일이 바뀌면 삭제하지 않습니다. 저장·이름 변경 대기 중인 파일은 아직 미리보기에 나오지 않을 수 있습니다. 이 기능은 밀리 접근성을 켜지 않아도 사용할 수 있습니다.

v1.4 · 알림을 눌러도 화면 유지

감시 알림, 캡처 알림, 이름 변경 결과, 테스트 알림을 눌러도 앱으로 이동하지 않습니다. 알림의 중지 버튼은 계속 동작합니다. 작은 번호창도 눌러서 앱이 열리지 않습니다.

v1.4 · 번호부터 빠르게

새 파일이 보이는 즉시 번호를 먼저 배정하고, 저장과 이름 변경은 뒤에서 처리합니다. 캡처 버튼 자체를 감지하는 기능은 아니므로 버튼과 완전히 동시에 바뀌는 것을 보장하지 않습니다. 실제 지연은 휴대폰의 파일 생성·폴더 제공 속도에 따라 다릅니다. 빠른 확인은 기존보다 배터리를 더 사용할 수 있습니다.

캡처 중 팝업 알림이 안 보이나요?

v1.1에는 ‘알림 테스트’, ‘팝업 알림 설정’, 최근 감지 기록이 추가되었습니다. 기존 앱을 지우지 않고 업데이트 설치하세요. 테스트 알림이 알림창에만 보인다면 앱의 ‘팝업 알림 설정’에서 소리 및 팝업을 허용하세요. 방해 금지나 휴대폰의 알림 제한에 따라 팝업은 표시되지 않을 수 있습니다. 테스트는 되는데 캡처를 감지하지 못한다면 선택한 폴더와 실제 캡처 저장 위치가 같은지 확인하세요.
